# 0001 — Dedicated quiz foundation and review gates

Date: 2026-10-28. Status: foundation proposal awaiting review.

## Context

`markknit/ares-tracking-system` is an existing repository. Quiz work must coexist with potential ARES usage tracking and retain its MIT license. Camera feasibility and assessment architecture have independent uncertainties.

## Direction specified by the bootstrap request

Keep quiz work under `quiz-tracker/`. Develop capture and assessment in separate tracks/worktrees. Separate reusable card observations from student assessment responses. Operate without Internet during classroom use. Evaluate open-source integration before committing to a complete custom backend.

## Consequences and gates

Do not select a database, platform, marker family, deployment route, or wire API in foundation. Review foundation before A1/B1, scanner feasibility after A7, and build/integrate recommendation after B5/B6. Review shared contracts centrally with both tracks. Defer integration until independent reliability has been demonstrated.

No reviewer approval is recorded here. Future decisions must record alternatives, evidence, consequences, status, and reviewer/date rather than treating a draft as approved.
